# CamUs

CamUs is a **lightweight, expandable camera application for Linux** built in Python. It provides a **lag-free interface** for capturing photos, recording videos, timelapse, zooming, and more. CamUs is designed to be easy to use and fully configurable.

---

## **Features**

- Expandable and resizable GUI (Tkinter)
- Safe resolution selection
- Zoom control
- Snapshots with optional countdown timer
- Video recording (without audio)
- Timelapse capture with configurable interval
- Face detection overlay (optional, can be disabled)
- Switch between multiple cameras
- Select custom save folder for media
- Refresh button to reset camera and controls
- Lag-free operation (no filters)
